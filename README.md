# Snake Game 🐍

A simple implementation of the classic Snake game built with **Python** and **Tkinter**.

## About the Project

This project was developed as an educational project for a **Python programming course** that I taught as an instructor.

The goal was to give students a practical example of how fundamental Python concepts can be combined to create a complete and interactive application.

## Technologies

* Python
* Tkinter

## Features

* Classic Snake gameplay
* Keyboard controls
* Score tracking
* Increasing snake length
* Simple and beginner-friendly code

## Purpose

This project is primarily intended for **educational purposes** and is designed to help Python beginners understand how basic programming concepts can be applied in a small interactive project.
